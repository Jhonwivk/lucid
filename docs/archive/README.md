# Documentation archive

This directory contains historical checkpoints retained for audit context. Archived material does not define current product behavior, release status or contribution requirements.

- `reports/stage1-*` and `reports/stage2-*` are milestone reports.
- `milestones/` contains the original specification, plan, acceptance checklist and task ledger.
- `adr/` contains superseded architecture decision records.
- `design/` contains superseded visual and language notes.
- `reports/screenshots/` contains historical UI captures.

Use the [current documentation index](../README.md), [architecture](../architecture.md), [product baseline](../product-baseline.md), [development guide](../development.md) and [release status](../release-status.md) for maintained guidance.
